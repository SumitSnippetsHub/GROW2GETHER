## Cannibalisation rules

- Website development owns “build my site”. Web design owns “how it looks and how the page is organised”.
- E-commerce owns shops in general. Shopify owns Shopify specifically. The two pages link to each other.
- Delhi owns the city query only. It links to the main website-development page.
- Old `/services/websites`, `/services/shops`, `/services/apps` and `/services/automations` 301 to the new URLs and are not in the sitemap.
